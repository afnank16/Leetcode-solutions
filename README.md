# Leetcode-Solutions

My LeetCode problem-solving archive, automatically synced from LeetCode as I solve problems.

## 📌 About

This repo tracks my journey solving problems on [LeetCode](https://leetcode.com). Every accepted submission is automatically pushed here, so this history reflects my actual solving activity over time.

## 🗂️ Structure

Each problem gets its own folder, named `<problem-number>-<problem-slug>`:

```
0001-two-sum/
  0001-two-sum.js
  README.md
0002-add-two-numbers/
  0002-add-two-numbers.py
  README.md
```

Each folder contains:
- `<number>-<slug>.<ext>` — my accepted solution, in whatever language I solved it in
- `README.md` — the full problem statement, pulled directly from LeetCode
